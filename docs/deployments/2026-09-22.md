## Recovery and remaining boundaries

From the source checkout, run:

```sh
.venv/bin/python scripts/deploy.py status
.venv/bin/python scripts/deploy.py rollback
```

The previous target is the exact legacy launcher. That version still has the
known DQL Recent Changes bug; first rollback verifies initialization, tool
catalog, and Vault listing while skipping that known-broken operation.
See [the deployment runbook](../deployment.md) for automatic recovery and
interrupted-transition handling.

production was not deliberately rolled back after successful activation.
The remote connector path was verified from this session, not by interacting
with the ChatGPT graphical interface. Reboot and sleep/wake remain untested.

this successful deployment does not establish its root cause.
