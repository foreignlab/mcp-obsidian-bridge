## Future updates and rollback

Edit the shared configuration's complete `write_folders` array and restart
the Tunnel LaunchAgent to reload it. See [configuration instructions](../../chatgpt/README.md).
Entries are exact top-level folder names; their subdirectories are included.
Omitting the setting retains the original two-folder policy, while an empty
array disables writes. Invalid settings prevent gateway startup.

The standard `scripts/deploy.py rollback` command restores the previous
release. It does not restore shared configuration. The previous release
ignores `write_folders` and enforces only `000_Inbox` and `020_Projects`.
The private backup preserves the pre-change configuration if restoration is
needed; never commit or display its credentials.
